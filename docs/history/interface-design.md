# 界面设计基线（v2 · 桌面端重构）

> 更新：2026-09-02  
> 设计来源：v2 高保真原型 `docs/design/handoff/`（已随 v3 界面重构删除，可在 git 历史中找回）  
> 实施契约：[redesign-plan.md](./redesign-plan.md)

本文描述当前已实现的界面基线。上一版（GPT 风格浅灰/绿色）已被本版替代。

## 设计方向

多工作空间 / 多看板的无限画布工作台。视觉以靛蓝强调色、低对比 1px 边框、10–16px 圆角和柔和阴影为主；所有状态必须同时用图标和文字表达，颜色只作辅助。界面文案中文优先，保留 en 键值。

## Token

所有颜色通过 `apps/web/src/styles/tokens.css` 的 CSS 变量提供，主题切换只换变量。

| 卡片 `--card` / `--card2`             | `#FFFFFF` / `#F5F6FA`                                     | `#1B1C21` / `#23252B`                                     |

字体：系统无衬线（PingFang SC 回退链）；代码、路径与数字用 `ui-monospace, Menlo`。不加载在线字体。

节点类型色：任务 `#2E7CF6` · Agent `#5B5BD6` · 终端 `#1F9D64` · 变更 `#8A4FD6` · 文件 `#D18F0F` · 上下文 `#0E9AA7` · 日志 `#6B7080` · 图片 `#E0762E` · 便签 `#B8860B` · 浏览器 `#0E9AA7`。

## 布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶栏 36：ws / board · Runtime · 保存 · 网关 · Git · Diff · ⌘K · 主题 · 设置 │
├──┬───────────┬──────────────────────────────┬────────────────┤
│轨│ 侧栏 236  │ 画布（点阵 24px）              │ Inspector 272  │
│52│ 看板      │ 右上：选择 / 画笔 / 一键整理   │ 属性 / 显示状态│
│  │ 项目文件  │ 左下：缩放柱 + 摘要提示        │ 连接 / 动作     │
│  │ 添加节点  │                              │ 复制 / 删除     │
├──┴───────────┴──────────────────────────────┴────────────────┤
│ 状态栏 24：本地/网关 · 会话统计 · 网关端口 · 路径                 │
└──────────────────────────────────────────────────────────────┘
```

- 启动页：左 300px 操作栏（打开项目位置 ⌘O / 新建工作空间 ⌘N / 连接远程网关（预留）/ 拖放区）+ 最近工作空间卡片网格。
- 节点头部约 26px：类型图标、标题、状态、`−`（缩小）与 `⤢`（聚焦）。
- 节点三态：mini 240×52 只显示头部；normal 完整内容；focus 占满画布可视区，Esc 退出。画布缩放低于摘要阈值（默认 60%，设置可调）时所有节点强制 mini。
- 默认尺寸：任务 280×250 · Agent 430×600 · 终端 480×280 · 变更 400×420 · 文件 300×230 · 上下文 280×150 · 日志 360×220 · 图片 260×200 · 便签 260×180 · 浏览器 520×380。
- 平板/手机沿用旧的单区域切换（`MobileNav`），工作空间轨在 768px 以下隐藏。

## 语义连线

`link ⇄ 软链接（虚线）` · `dispatch ➤ 派发给` · `produce ◆ 产出` · `write ✎ 写入` · `trigger ⚡ 触发` · `ref @ 引用（虚线）`。

从右侧端口拖到目标节点松开后弹出语义选择层，数字键 1–6 快选，Esc 取消；推荐语义排第一。连线中点显示 `图标 + 标签 + →`，选中相关节点时高亮为强调色。

## 拖拽、粘贴与工具栏

- 文件 → File 节点；文件夹 → Context 节点；图片 → Image 节点；节点类型卡 → 对应节点；拖到 Agent 节点 → 新建节点 + `ref` 连线 + 上下文 chip。拖动中画布显示虚线高亮与"松开创建 ××"提示。
- 粘贴文本 → 便签（首行作标题，可转为任务）；粘贴图片 → 图片节点。
- 画笔：5 色，笔迹以世界坐标存于 `board.strokes`，随缩放同步；"清除笔迹"。
- 一键整理：按连线拓扑深度分列，列内纵向堆叠，无连线放最后一列，完成后适应画布。

## 快捷键

⌘K 命令面板 · ⌘N 新建工作空间 · ⌘O 打开项目 · ⌘⇧N 新建看板 · ⏎ 聚焦选中 · Esc 退出/取消 · ⇧1 适应画布 · ⇧0 100% · ⌫ 删除 · ⌘⏎ 运行 Agent · ⌘⇧L 一键整理 · ⌘⇧T 切换主题。

## 动效原则

沿用 Motion 且只动画 `opacity` / `transform`：弹层 ≤160ms 淡入，节点选中只改描边与阴影，`running` / `connecting` 状态图标的旋转是唯一循环动画。`prefers-reduced-motion` 与强制颜色模式保留。

## 诚实边界

- 网关与外部端为预留：UI 只显示「已关闭」或「已启用 · 预留」，不显示伪造设备；Runtime 的 `/api/gateway` 不监听端口。
- Agent 头部的 tokens 计数只在 Agent 通过 ACP 提供 `usage` 时显示。
- 浏览器节点为沙箱 iframe；「截图到画布」在接入桌面 WebView 前保持禁用。
- 启动页卡片不显示 Git 分支（列表接口不含 Git 信息）。
