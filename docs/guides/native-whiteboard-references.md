# 原生白板内容引用

白板上的文字、几何图形、图片、手绘与直线都可以作为 Agent 的资料。对象右键选择「引用到 Agent」，挑一个 Agent 终端即可建立引用；也可以从节点侧面的把手拖一条线落到白板对象上。重复引用同一对象与同一个 Agent 不会画出第二条，而是选中已有的那条。引用线是灰色虚线加一个指向节点的箭头，选中后线上会浮出一个按钮删除这条引用（白板对象本身不受影响）。每个 Agent 最多引用 64 个唯一对端（含连线连到的其他节点），菜单与拖线超过上限都会阻止并明确提示。

Agent 按需执行：

```sh
armadra-hook context list
armadra-hook context summary --node '<引用标题或 ID>'
```

连线不会自动给 CLI 发消息、按 Enter、修改 provider 配置或追加系统提示。Desktop 和 Web 使用同一前端、Runtime API 和节点身份协议。

## 存储模型

一条引用是白板文档 `whiteboard_json` 里的一行 `{ id, itemId, nodeId }`，不占用节点之间的 `edges` 行，也不再是一条带两端绑定的箭头。`id` 同时是 `ContextLink.id` 与 `.armadra/exports/<id>.png` 的文件名，所以刷新与重新加载之后引用身份、导出文件与线的位置都不变。删除被引用的对象会连带删掉指向它的引用行；这一步和其他画布修改一样进撤销栈。

## 读取契约

已有 `ContextLink { id, title, kind: "shape", content }` 保持兼容。可选字段：

- `sourceShapeId` / `shapeType`：资料来自哪个白板对象。`sourceShapeId` 形如 `wb:<uuid>`，`shapeType` 是 `text` / `shape` / `ink` / `image` / `line`。类型只是提示，Runtime 不按它分支。
- `status`：`pending` 表示图片准备中；`ready` 表示前端提取/上传完成；`error` 表示提取或上传失败。Runtime 仍在读取时检查图片文件确实存在且位于当前工作区中。
- `text` / `pngPath`：提取文字与工作区相对图片路径，二者可同时存在。失败与准备期间仍可读取已提取的文字，不将旧图片当作最新结果返回。
- `textTruncated`：文字超过 20000 UTF-8 字节时明确提示截断，不破坏 Unicode 字符。

文字对象只提供正文，不导出图片；带标签的几何图形同时提供文本和图片；手绘、直线与无标签的图形只提供图片。工作区内受管理的图片（`.armadra/assets/<hash>.<ext>`）直接复用资产文件，不重复导出；其他来源的图片导出可见像素。缺少图片、浏览器导出失败或网络上传失败均不会变成空内容的成功缓存。

## 生成与同步

PNG 由前端自己栅格化（`canvas/whiteboard/raster.ts`，与屏幕上同一份路径数据），密度 2、留白 16，底色跟随画布纸张色，最长边超过 4096 像素时自动降密度而不裁剪。

文字和准备状态先发布，PNG 按两秒截止时间批量生成；连续的其他文档编辑不会无限推迟生成。导出任务串行运行，内容版本改变时丢弃过时结果。判断「内容是否变了」看的是对象自身的 JSON 去掉 `x` / `y`——只挪位置不重新导出，改尺寸、样式、正文或换图都会重导。生成失败最多尝试三次，之后保留明确失败状态；右键「重新同步引用」可主动重试。

每个看板的链接文档 PUT 串行发送，只有收到成功响应后才记录已发布，避免旧的慢请求覆盖新内容。网络失败可自动重试三次；耗尽后显示带「重新同步」动作的错误提示，成功后清除。恢复在线或手动重新同步可再次触发。图片资产的显示 URL 依据当前 Runtime 与工作区重建，避免保留旧开发端口。

## 验证范围

回归覆盖：菜单与拖线两条路建出同一种引用行、重复引用定位已有的那条、上限计入连线对端并挡住第 65 条；文字 / 图形标签 / 手绘 / 受管图片四种内容的字段组合；只挪位置不重导、改内容重导；导出失败保留文字并在三次后停在 `error`、显式重新同步后转 `ready`；引用边只画一个指向节点的箭头且选中后可删；串行发布、有界重试、卸载取消；同一对象的两行引用在链接文档里去重。

此版本仍采用前端生成的资料快照，未将图形内容解析或 PNG 渲染搬入 Rust。没有打开画板前端时，不生成新的图形导出；后台 CLI 可读取最近已同步的资料。引用数量沿用每节点 64 条上限。分组（Frame）作为引用来源尚未提供：引用的一端必须是白板对象。
