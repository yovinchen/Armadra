# AI Coding Canvas · 界面重构交接说明

原型：`AI Coding Canvas v2.dc.html`（1440×900，浅/深双主题）。本文件描述让现有 Tauri 项目按原型修改所需的结构、状态与交互规则。

## 1. 应用结构

```
Launcher（启动页）
└─ Workspace（工作空间 = 一个项目位置）
   ├─ boards[]  默认含 "Default" 空看板
   ├─ files     项目文件树
   ├─ gateway   网关配置（外部端接入）
   └─ Board
      ├─ nodes[] / edges[] / strokes[]
      └─ viewport { scale, tx, ty }
```

- 数据持久化：每个 Workspace 一个目录 `.aicanvas/`，`workspace.json` + `boards/<id>.json`。
- 最近工作空间列表保存在应用级配置。

## 2. 布局（主工作区）

| 区域       | 宽/高  | 内容                                                                                     |
| ---------- | ------ | ---------------------------------------------------------------------------------------- |
| 顶栏       | 36px   | 面包屑 ws / board、Runtime 状态、保存状态、网关状态、Git 状态、扫描 Diff、⌘K、主题、设置 |
| 工作空间轨 | 52px   | 每个 ws 一个色块字母图标，运行中显示角标；＋新建；底部网关、设置                         |
| 侧栏       | 236px  | 看板列表（＋）、项目文件树（可拖）、添加节点面板（可拖）                                 |
| 画布       | 自适应 | 无限画布、点阵背景、右上工具栏、左下缩放控件                                             |
| Inspector  | 272px  | 选中节点属性 / 连接 / 可执行动作；未选中显示看板概览与外部端状态                         |
| 状态栏     | 24px   | 本地/网关模式、活动会话统计、网关端口、路径                                              |

## 3. 节点类型

task 任务 · agent Agent(ACP) · terminal 终端 · diff 变更 · file 文件 · context 文件夹引用 · note 便签 · browser 嵌入浏览器 · attachment 图片 · log 日志

通用字段：`id,type,title,subtitle,status,x,y,w,h,zoom('mini'|'normal'|'focus'),body?,url?`

状态枚举（必须同时有图标 + 文字，不能只靠颜色）：
running ◐ 运行中 · waiting ⏸ 等待确认 · done ✓ 已完成 · review ◇ 待审阅 · modified ● 已修改 · idle ○ 空闲 · error ✕ 失败 · disconnected ⊘ 已断开 · connecting ◌ 连接中 · linked ⇄ 已引用

### 缩放三态

- mini：240×52，只显示图标、标题、状态；
- normal：完整内容；
- focus：占满画布可视区，Esc 退出；
- 画布 scale < 阈值（默认 60%，可设置）时所有节点强制 mini。

## 4. 连线语义

`link 软链接(虚线)` · `dispatch 派发给` · `produce 产出` · `write 写入` · `trigger 触发` · `ref 引用(虚线)`

- 从节点右侧端口拖到目标节点松开 → 弹出语义选择层（数字键 1-6 快选，Esc 取消）。
- 连线中点显示 `图标 + 标签 + →`，带箭头；选中相关节点时高亮。

## 5. 拖拽 / 粘贴创建规则

| 来源               | 落点       | 结果                                                                 |
| ------------------ | ---------- | -------------------------------------------------------------------- |
| 文件               | 画布       | File 节点                                                            |
| 文件夹             | 画布       | Context 节点（作为上下文注入）                                       |
| 图片文件           | 画布       | Image 节点                                                           |
| 节点类型卡         | 画布       | 对应新节点                                                           |
| 文件/文件夹        | Agent 节点 | 新建 File/Context 节点 + 自动 `ref` 连线 + 加入该 Agent 上下文 chips |
| 粘贴文本           | 画布       | Note 便签（首行作标题，可"转为任务"）                                |
| 粘贴图片           | 画布       | Image 节点                                                           |
| 拖到窗口（启动页） | —          | 新建工作空间                                                         |

拖动过程中画布显示虚线高亮与提示文案（"松开创建 ×× 节点"）。

## 6. 画布工具栏（右上）

- 选择 / 画笔 切换；画笔模式：5 色，笔迹存于 `board.strokes[{color,pts[]}]`（世界坐标），随缩放同步，"清除笔迹"。
- 一键整理：按连线拓扑深度分列（源节点在左），列内纵向堆叠，无连线节点放最后一列，完成后自适应画布。
- 便签 / 浏览器 快捷新建。

## 7. Agent 节点（ACP）

- 头部：ACP 状态（已连接 v1 / 协商中 / 离线）、提供方切换（Claude Code / Codex / Gemini CLI）、tokens、耗时。
- 时间线消息类型：`user` `assistant` `thinking(可折叠)` `tool(名称/参数/结果状态)` `permission`。
- 权限卡：允许一次 / 始终允许 / 拒绝；决策后写回并显示结果；**同一请求同步推送到外部端，任一端确认即生效**。
- 底部：上下文 chips（可移除，可拖文件加入）、输入框（Enter 发送）、停止、"携带上下文运行"。

## 8. 终端 / Diff / 浏览器 / 便签

- 终端：真实 PTY，头部连接状态 + PID，底部 清屏 / 重连 / 停止(运行时) / 重新运行(空闲时)，退出码摘要。
- Diff：文件列表 + M/A 标记 + 增删统计 + patch 展开；单文件与全部的 接受/回滚；顶栏"扫描 Diff"抽屉可一键放为 Diff 节点。
- 浏览器：WebView 独立会话（与 Agent Cookie 隔离），地址栏 / 前进后退刷新 / 系统浏览器打开；网页选中文本可拖到 Agent；"截图到画布"生成 Image 节点。
- 便签：纯文本编辑，字数统计，"发送给 Agent" / "转为任务"。

## 9. 网关与外部端（预留）

- 本机 Runtime 即网关：`127.0.0.1:7420` + 局域网地址；WebSocket + JSON-RPC；TLS 自签。
- 鉴权：设备配对 Token（30 天）；设置页可配对 / 撤销设备。
- 外部端权限：查看 ✓、确认权限请求 ✓、执行命令 ✕（默认）。
- 事件模型建议：`board.changed` `node.status` `agent.message` `agent.permission.request/resolve` `terminal.output` `diff.updated`，外部端订阅同一 board。
- UI 处处显示网关状态（顶栏、轨底部、Inspector、状态栏、日志节点的"网关"过滤）。

## 10. 弹层

- 新建工作空间：名称、项目位置(浏览)、读/写/执行权限、允许外部端接入开关 → 创建后自动打开 Default 看板。
- 设置：模型与提供方 / ACP 协议 / 网关与外部端 / 外观（浅深主题、语言、摘要阈值） / 快捷键。
- ⌘K：分组 创建 / 跳转 / 命令，支持模糊搜索。

## 11. 快捷键

⌘K 命令面板 · ⌘N 新建工作空间 · ⌘O 打开项目 · ⌘⇧N 新建看板 · ⏎ 聚焦选中 · Esc 退出/取消 · ⇧1 适应画布 · ⇧0 100% · ⌫ 删除 · ⌘⏎ 运行 Agent · ⌘⇧L 一键整理 · ⌘⇧T 切换主题

## 12. 视觉

- 浅色：bg #F3F4F8 / 面板 #FFF / 强调 #5B5BD6；深色：bg #0E0F12 / 面板 #15161A / 强调 #7C7CF0。
- 圆角 10–16px，柔和阴影，边框 1px 低对比；系统无衬线字体，代码/路径用等宽。
- 所有颜色以 CSS 变量提供，主题切换只换变量。
