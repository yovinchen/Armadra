# Handoff: Armadra 桌面端界面重构

## Overview

面向 Tauri 桌面应用 armadra 的整套界面重构：启动页、多工作空间/多看板、无限画布节点系统（Task / Agent(ACP) / Terminal / Diff / File / Context / Note / Browser / Image / Log）、语义连线、拖拽粘贴创建、手绘标注、一键整理、⌘K、设置、Diff 扫描抽屉、网关与外部端预留。

## About the Design Files

本包中的 HTML 文件是 **用 HTML 制作的设计参考原型**，用于展示预期外观与行为，**不是可直接复用的生产代码**。任务是在目标代码库现有环境（Tauri + 前端框架）中，用其既有模式与组件库**重新实现**这些设计。

## Fidelity

**High-fidelity**。颜色、字号、间距、圆角、阴影、交互状态均为最终值，请按像素级还原，并接入真实数据（PTY、ACP、Git、文件系统、网关）。

## 文件

- `Armadra v2.dc.html` — 完整可运行原型（在浏览器中打开；顶部切换器可查看各画面与浅/深主题）。
- `src/template.html` — 原型的视图模板（内联样式即为设计规格；`{{ }}` 为数据槽，`sc-for`/`sc-if` 为循环/条件）。
- `src/logic.js` — 状态机与交互逻辑（节点/连线/笔迹数据结构、拖拽/粘贴规则、缩放三态、自动整理算法、ACP 时间线、Diff 状态、网关状态等）。
- `SPEC.md` — 结构化规格说明（布局尺寸、枚举、规则、快捷键、设计令牌）。

## 实现顺序建议

1. 主题变量（SPEC §12）与应用壳布局（SPEC §2：顶栏 36 / 轨 52 / 侧栏 236 / Inspector 272 / 状态栏 24）。
2. Workspace / Board 数据模型与持久化（SPEC §1），启动页 + 新建工作空间弹层。
3. 画布：平移缩放、点阵背景、节点拖动、三态缩放、摘要阈值、连线与语义弹层。
4. 各节点内部（SPEC §7–8），接入真实 PTY / ACP / Git diff。
5. 拖拽与粘贴创建（SPEC §5），画笔与一键整理（SPEC §6）。
6. ⌘K、设置页、Diff 扫描抽屉。
7. 网关：事件总线与外部端订阅（SPEC §9）。

## 约束

- 文案全部中文；所有状态必须同时用图标 + 文字表达，不能只靠颜色。
- 节点头部保持紧凑（≈26px），只显示类型图标、标题、状态、两个控制键。
- 节点类型的创建入口统一在左侧「添加节点」面板与 ⌘K，画布工具栏只放选择/画笔/一键整理。
