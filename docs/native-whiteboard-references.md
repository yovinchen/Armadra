# 原生白板内容引用

文字、原生便签、几何图形、图片、手绘、直线、高亮、画框与组合均可作为 Agent 的资料。原生对象右键选择「引用到 Agent」，选择一个 Agent 终端后建立真正的 tldraw arrow 与双端绑定；重复选择同一对象与 Agent 会定位已有引用。自动引用线采用中性灰色；每个 Agent 最多引用 64 个唯一对象（含其他节点），新增菜单和手动拖线超过上限都会阻止并明确提示。也可沿用箭头工具手动连接。普通不支持格式不会被伪装成文本资料。

Agent 按需执行：

```sh
armadra-hook context list
armadra-hook context summary --node '<引用标题或 ID>'
```

连线不会自动给 CLI 发消息、按 Enter、修改 provider 配置或追加系统提示。Desktop 和 Web 使用同一前端、Runtime API 和节点身份协议。

## 读取契约

已有 `ContextLink { id, title, kind: "shape", content }` 保持兼容。新增可选字段：

- `sourceShapeId` / `shapeType`：资料来自哪个原生对象。
- `status`：`pending` 表示图片准备中；`ready` 表示前端提取/上传完成；`error` 表示提取或上传失败。Runtime 仍在读取时检查图片文件确实存在且位于当前工作区中。
- `text` / `pngPath`：提取文字与工作区相对图片路径，二者可同时存在。失败与准备期间仍可读取已提取的文字，不将旧图片当作最新结果返回。
- `textTruncated`：文字超过 20000 UTF-8 字节时明确提示截断，不破坏 Unicode 字符。

文字直接读取；便签和带文字的图形同时提供文本和图片。画框/组合包含其原生子孙文字与整体导出图。受管理且未经裁剪、翻转、旋转的图片可以复用资产文件；旧 data URL、无路径元数据和视觉变换后的图片会导出可见像素。缺少图片、浏览器导出失败或网络上传失败均不会变成空内容的成功缓存。

## 保存与同步

原生内容箭头保存在白板快照，不占用节点之间的 `edges` 行。文档节点 frame 内的原生子孙也保存在白板快照，不能因为父 frame 由节点表承载就丢弃。重载时先投影文档节点，再按父子顺序恢复原生子孙，最后恢复 bindings；坐标、内容与引用身份保持不变。

文字和准备状态先发布，PNG 按两秒截止时间批量生成；连续的其他文档编辑不会无限推迟生成。导出任务串行运行，内容版本改变时丢弃过时结果。生成失败最多尝试三次，之后保留明确失败状态；右键「重新同步引用」可主动重试。

每个看板的链接文档 PUT 串行发送，只有收到成功响应后才记录已发布，避免旧的慢请求覆盖新内容。网络失败可自动重试三次；耗尽后显示带「重新同步」动作的错误提示，成功后清除。恢复在线或手动重新同步可再次触发。图片资产的显示 URL 依据当前 Runtime 与工作区重建，避免保留旧开发端口。

## 验证范围

回归覆盖：菜单创建真实双端绑定与重复引用去重；原生便签文字与图片；旧 data URL 图片导出；资产变化/旋转导致缓存失效；失败状态保留文字和无编辑自动重试；串行发布、有界重试、重新同步与卸载取消；嵌套原生子孙保存与父子顺序恢复；Runtime 正确返回准备/失败/文件不存在状态，拒绝越界图片路径。

此版本仍采用前端生成的资料快照，未将图形内容解析或 PNG 渲染搬入 Rust。没有打开画板前端时，不生成新的图形导出；后台 CLI 可读取最近已同步的资料。引用数量沿用每节点 64 条上限。
